# 正式简报（`formal-brief`）

## 定位

面向政策说明、机构动态、专题报告和阶段总结的文档型主题。海军蓝页眉、摘要框和清晰的 `SECTION` 层级让内容像一份可归档简报，而不是宣传海报。

## 变量

| 角色 | 值 | 用途 |
|---|---|---|
| 纸张 | `#FFFFFF` | 文档背景 |
| 主墨 | `#152334` | 标题和结论 |
| 正文 | `#354455` | 正文内容 |
| 辅助 | `#627184` | 口径和注释 |
| 强调 | `#234E70` | 页眉、章节竖线、表头 |
| 浅底 | `#F2F5F8` | 摘要、列表、说明 |

## 组件原则

- Hero：海军蓝文档页眉 + 标题 + 左线摘要区。
- 目录：使用“报告目录”，每项为浅底文档行。
- 章节：左侧海军蓝竖线 + `SECTION 01`。
- 表格与指标：深蓝表头、浅蓝灰底，强调口径而非装饰。
- 文末：使用“报告说明”，提醒区分事实、解释和判断，不使用涨粉话术。

## 文章骨架

页眉 → 标题 → 摘要 → 报告目录 → 背景 → 事实与数据 → 解释 → 阶段性结论 → 报告说明。

## 适用映射

- 适合：政策解读、机构报告、项目进展、研究摘要、正式声明分析。
- 慎用：只有个人情绪、缺少事实层级的随笔。
- 不适合：娱乐化热点、强促销、生活方式图文。
