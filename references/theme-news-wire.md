# 新闻线（`news-wire`）

## 定位

面向新闻解读、事件进展和事实核查的极简报道主题。视觉母题是报纸栏线：依靠粗细横线、标题字号和紧凑编号建立层级，不使用渐变、投影、圆角卡片或装饰图形。

## 变量

| 角色 | 值 | 用途 |
|---|---|---|
| 纸张 | `#FFFFFF` | 全文背景 |
| 主墨 | `#111827` | 标题与关键结论 |
| 正文 | `#303844` | 正文长读 |
| 辅助 | `#5F6873` | 栏目标识与说明 |
| 强调 | `#273746` | 顶栏、编号、边界线 |
| 浅底 | `#F5F6F7` | 列表和信息模块 |

## 组件原则

- Hero：`NEWS DESK · 事实报道` + 主标题 + 双细线摘要。
- 目录：使用“报道提要”，每项一行，不做并排卡片。
- 章节：上边黑线 + `REPORT 01`，适合时间线和调查进展。
- 引用与信息模块：只保留细边框和浅灰底。
- 文末：使用“信息说明”，不出现“在看、转发、星标”等营销式话术。

## 文章骨架

标题 → 摘要 → 报道提要 → 已知事实 → 最新进展 → 未决边界 → 信息说明。

## 适用映射

- 适合：新闻跟进、事实核查、公共事件解释、调查进展。
- 慎用：人物抒情、品牌发布、教程清单。
- 不适合：需要强烈视觉营销或大量产品卡片的文章。
