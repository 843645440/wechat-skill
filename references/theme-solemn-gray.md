# 沉静灰（`solemn-gray`）

## 定位

面向伤亡事件、事故复盘、纪念和公共安全议题的克制主题。暖灰纸面、宋体正文和极少量暗酒红用于提示风险与未决信息；不借黑底、血红或巨大数字制造冲击。

## 变量

| 角色 | 值 | 用途 |
|---|---|---|
| 纸张 | `#FDFCFA` | 暖白背景 |
| 主墨 | `#1C1B1A` | 标题与主要判断 |
| 正文 | `#3B3835` | 宋体长读 |
| 辅助 | `#6A645F` | 来源、范围和注释 |
| 强调 | `#712F38` | 小面积风险提示 |
| 浅底 | `#F3F0ED` | Hero 与引用区 |

## 组件原则

- Hero：`SPECIAL REPORT · 重大事件`，暖灰底、黑色顶线，不使用深色满版。
- 目录：使用“事件脉络”，编号仅做细框，不做徽章。
- 章节：暗酒红细框编号 + 长横线，保留足够呼吸感。
- 正文：宋体、较高行距；强调只加细下划线，不铺高饱和底色。
- 文末：使用“阅读说明”，强调克制、事实边界和司法边界，删除互动催促。

## 文章骨架

标题 → 克制摘要 → 事件脉络 → 事实时间线 → 影响与责任 → 尚未查清 → 阅读说明。

## 适用映射

- 适合：枪击、事故、灾害、公共安全、历史悲剧复盘。
- 慎用：争议尚无可靠来源、需要实时滚动的短快讯。
- 不适合：轻松测评、工具清单、促销和品牌活动。
