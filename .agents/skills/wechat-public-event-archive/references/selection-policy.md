# 选题与核验规则

## 栏目定位

栏目是基于中国官方公开材料的历史人物与公共事件复盘，不是实时爆料、猎奇罪案或“黑老大传奇”。
允许类别以 `config/public-event-archive.json` 为准，默认覆盖：

- 涉黑涉恶案件
- 贪腐与职务犯罪
- 重大诈骗、非法集资与传销
- 重大安全生产或公共事故
- 食品药品、环境污染等公共安全事件
- 造成广泛社会影响的重大刑事案件

## 两类准入门禁

### 人物犯罪稿

必须全部满足：

1. 已有生效裁判；来源明确写出“已发生法律效力”“二审维持原判”或能确认未上诉且生效。
2. 至少一份法院、检察院、生效裁判或官方典型案例材料。
3. 至少一篇新华社、央视、人民日报等中国官方媒体报道。
4. 姓名、身份、罪名、金额、刑罚和关键日期能在来源间相互印证。

中央纪委国家监委的审查调查、处分或“双开”通报不能替代刑事裁判。没有生效裁判时，不得称
某人为“贪污犯”“受贿犯”“诈骗犯”或其他已经定罪的身份。

### 重大事件稿

必须全部满足：

1. 已有政府或主管部门调查报告、责任认定、正式通报，或者其他稳定的官方结论。
2. 至少一篇中国官方媒体报道，且与官方结论不存在关键冲突。
3. 事件的伤亡、损失、责任主体、处理结果等核心事实已经稳定。
4. 公开材料足以支撑完整复盘，不需要模型猜测原因、动机或责任。

正在调查、核心数字仍变化、责任认定未完成的事件暂不写。

## 信源分层

主信源优先级：

1. 法院、检察院、中央纪委国家监委、公安机关、国务院及各级政府的正式材料。
2. 生效裁判、官方典型案例、调查报告、责任认定、正式新闻发布会实录。
3. 新华社、央视、人民日报等中国官方媒体的独立报道。
4. 地方官方媒体只作补充；普通商业媒体只可用于找线索，不进入最终事实链。

每个具体数字、罪名、刑罚、时间和关键行为都要映射到来源。搜索摘要只能帮助定位网页，不能
直接作为证据；必须打开原文核对。转载稿优先回溯到首发机关或首发媒体。

## 排序

通过硬门禁后按配置权重排序，默认：

- 社会影响：25
- 信源权威性：25
- 公开事实完整度：20
- 公共利益与警示价值：15
- 时间线及叙事完整度：10
- 栏目、年代和地域多样性：5

判决或官方结论的确定性不参与打分，因为它已是准入条件。来源冲突、隐私风险、必须猜测才能
成文或与历史记录重复，直接淘汰，不以高分抵消。

## `case_key` 与去重

- 人物：`person:<规范姓名>:<生效裁判日期或案号>`
- 事件：`event:<官方事件名称>:<官方结论日期>`

同一犯罪组织拆成多个成员稿时，只有公开材料足以分别呈现不同人物作用才允许；否则视为同题。
别名、简称和同一事件的后续报道必须归并到同一个 key。

## `source-dossier.json`

写入 `work/<account>/current/source-dossier.json`：

```json
{
  "schema_version": 1,
  "case_key": "person:示例姓名:2020-01-01",
  "subject": "示例姓名",
  "category": "major_fraud",
  "conclusion": {
    "type": "effective_judgment",
    "status": "effective",
    "authority": "某人民法院",
    "date": "2020-01-01"
  },
  "claims": [
    {
      "id": "C1",
      "text": "经生效裁判确认的事实",
      "source_ids": ["S1", "S2"]
    }
  ],
  "sources": [
    {
      "id": "S1",
      "publisher": "官方机构或官方媒体",
      "url": "https://www.court.gov.cn/article",
      "published_at": "2020-01-01",
      "source_type": "authority"
    },
    {
      "id": "S2",
      "publisher": "中国官方媒体",
      "url": "https://www.news.cn/article",
      "published_at": "2020-01-02",
      "source_type": "official_media"
    }
  ],
  "privacy_flags": [],
  "open_questions": [],
  "verified_at": "2026-01-01T00:00:00Z"
}
```

要求：

- `source_type` 只用 `authority` 或 `official_media`。
- 所有 `claims[].source_ids` 必须能在 `sources` 中找到。
- `open_questions` 只能用于提醒文章不要越界，不能改写成推测。
- 不大段复制来源原文，只记录简短事实转述。

## 写作口径

建议顺序：最终结论 → 人物或事件背景 → 如何形成或发生 → 已确认的主要事实 → 调查、侦破或
追责 → 判决或处理结果 → 暴露出的治理问题 → 公开信息边界。

统一措辞：

- “法院生效裁判认定……”
- “官方调查报告认定……”
- “新华社/央视当时报道……”
- “现有公开材料未披露……”

禁止使用“惊天黑幕”“罪恶一生”“终于遭报应”等煽动或侮辱性表达。标题保留具体人物/事件和
最终处理结果，不把未经裁判确认的指控写成结论。

## 隐私与排除项

以下任一情况直接排除：

- 未成年人身份或可反向识别信息成为主要叙事素材。
- 性侵、家暴等案件需要暴露被害人身份、住址、就学、医疗等信息才能成文。
- 普通家属、证人、举报人并非公共利益叙事所必需。
- 来源只有自媒体、匿名爆料、论坛帖子或无法回溯的转载。
- 文章会把个案泛化为对地域、职业、族群或其他群体的污名化。
