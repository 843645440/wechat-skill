# 认知读书写作

账号写哪本书、简介、封面，只看 `config/reading-books.json`。不要临场另找书、不要另做封面。

读者是**普通人**。主场是生活判断，不是投资课。

## 每次必读

- 本页。
- [references/writing-checklist.md](references/writing-checklist.md)
- 工作区 `book-intro.md`（固定简介，总介绍篇必用）
- 连载篇再读 `reading-slice.md`

流水线入口仍是 `../wechat-content-pipeline/SKILL.md`。

## 两种稿

**总介绍（该书第一篇，`piece=intro`）**

1. 标题：`全世界富豪都推荐读的一本书，里面到底能学到什么？答：四字`（≤32 字）。
2. 开头照抄 `book-intro.md` 的事实，不扩成人物传。
3. 后半写普通人能用什么、会影响什么。投资人那截点到即可。
4. 封面用配置里的公用图，不要按标题重生。

**连载（`piece=serial`）**

1. 标题导师口吻两截：为什么你＋笨办法？其实不是 A，是 B。办法不要写进标题。
2. 从 `reading-slice.md` 挖一个判断，译成生活语言。
3. 不要再写一遍固定简介。

## 硬规则

1. 标题 ≤32 字。总介绍用「答：四字」；连载用导师两截句。
2. 禁止小说开场、禁止把书里的人写成主角。
3. 引文来自固定简介或当前切片。没有的话不许编。
4. 专业原句下一句必须译成人话。
5. 封面只用该书公用封面。

## 输出

`article.md`（1500–4000 纯正文汉字）+ `digest.txt`（≤50 字，不复述标题）。
