# 标题与开头：最贵的那 3 秒

公众号的转化漏斗有两道极窄的闸门：**标题决定有没有人点，开头决定点了的人跑不跑。**
一篇 3000 字的文章，命运基本在前 200 字里定了。

## 一、标题：只有前 16 字是可靠的

订阅号信息流、聊天列表、分享卡片，三个场景截断长度不一样，但**前 16 个汉字左右
是唯一在所有场景都完整露出的部分**。所以刺点必须前置——不是「标题要短」，是
「狠的那半句要在前面」。

### 第 0 条：标题必须回答「谁 + 干了什么」

这是**优先于刺点**的一条。刺点解决「想不想点」，主体解决「知不知道这是什么」。
两者缺一不可，而缺主体是更致命的那一种——读者在推荐页只看得到标题，
如果说不出这写的是谁、哪件事，他连要不要点都判断不了。

```
❌ 省下的 90% 成本没有消失，它原来是某个人的工资
```

这个标题有数字、有断言、有反差，念出来很有力。但读者不知道它在说什么：
裁员？云账单？外包？AI？**「某个人」不是主体，「成本」也不是主体。**

```
✅ AI短剧播放破2亿，横店13万群演抢800个通告
```

同一篇文章。现在读者一眼就知道：主体是 AI 短剧和横店群演，
事情是一个火了、一个没活干。刺点（两个数字的对撞）一点没少。

自查方法：**把标题念给一个不知道你在写什么的人听，问他「这篇讲的是谁」。**
答不上来就重写。

体检脚本会检查这一条（`has_subject` 字段），但它只认得出外文专名、作品名、
数字实体、人群词和地名——**纯中文的技术名词（比如「多智能体」）会被漏判**，
所以它给的是 medium 级提醒，不是判决。命中时人工核一下。

### 四类刺点（任选其一，可叠加）

**1. 数字锚定** —— 最稳定的一类。

```
✅ 贵一倍不等于更强，两个模型怎么选
✅ 我把五篇旧稿丢进体检脚本，最高 67 分
❌ 关于模型选型的一些思考
```

数字之所以有效，是因为它承诺了**确定性**：读者知道点进去能得到具体的东西。

**2. 反差结构（不是 A，而是 B）** —— 制造认知缺口。

```
✅ 写了 2000 字没人读完，问题真不在文笔
✅ 卡住你的不是算力，是审批流
```

要点：A 必须是读者本来就相信的东西。反的不是常识，是**读者脑子里的默认答案**。

**3. 否定断言 / 损失框架** —— 行为经济学里最稳的杠杆。

```
✅ 别急着上多智能体，先算这三笔账
✅ 这三种情况下，升级只会更慢
```

**损失厌恶**：同一件事，「你会损失什么」比「你会得到什么」更容易被点开。
「别再花冤枉钱」＞「教你省钱」。

**4. 对号入座 + 决策疑问**

```
✅ 如果你团队只有三个人，这套流程别抄
✅ 三行代码会直接 400，该不该升
```

「如果你是 X」把一部分人挡在门外，反而提高了留下的人的完读率。**别追求所有人点开。**

### 标题禁区

| 反面模式 | 例子 | 为什么废 |
|---------|------|---------|
| 通报体 | `某某把 X 引入 Y，Z 转向 W` | 没有立场，读者不知道关自己什么事 |
| 名词堆砌 | `AI 时代的内容生产范式变革` | 抽象词不构成信息 |
| 周报腔 | `关于 X 的几点思考` | 「思考」是过程，读者要结果 |
| 万能疑问 | `X，你怎么看？` | 把判断推给读者＝作者没有判断 |
| 纯情绪 | `太离谱了！！！` | 没有信息锚，点开率高、取关率更高 |

### 标题党的账要算清楚

标题党能骗到打开率，但代价立刻兑现：**打开高、完读低**，这个组合在推荐系统里是
明确的负面信号（见 distribution-2026.md），在读者那里是「这号不可信」。

判断标准很简单：**标题里的承诺，正文前三分之一必须兑现。**兑现不了就换标题，
不是删承诺。

### 出三个候选再选

写完正文再回来写标题。三个候选分别用不同刺点（数字 / 反差 / 损失），然后按
五项打分选一个：

1. 前 16 字有没有刺点
2. 承诺正文兑不兑现得了
3. 有没有具体信息（不是抽象词）
4. 读者会不会觉得「这说的是我」
5. 念出来顺不顺口（公众号标题会被口头转述）

## 二、开头：150 字定生死

### 三种好开头

**冷开场**——直接给一个画面或动作，不解释。

> 昨天我把五篇已经发出去的旧稿，一篇一篇丢进体检脚本。

读者的大脑会自动追问「然后呢」。这就是你要的。

**反常识断言**——先把结论砸出来，再倒回去解释。

> 卡住这条流水线的从来不是模型能力。是一个没人愿意签字的验收环节。

**代价前置**——先说读者会损失什么。

> 这个配置错了，你不会报错。你会在三个月后收到一张多出 40% 的账单。

### 开头禁区（体检脚本会直接判 high）

```
❌ 在当今人工智能飞速发展的时代……
❌ 随着技术的不断进步……
❌ 近年来，越来越多的人开始关注……
❌ 众所周知，X 是一个重要的话题……
❌ 提到 X，相信大家都不陌生……
```

这些句子的共同点：**删掉之后文章毫发无损**。删掉之后文章毫发无损的句子，
就该删掉。尤其是第一句——它占着最贵的位置。

### 硬指标

- 第一个具体信息必须出现在 **150 字之内**（体检脚本量的就是这个）。
- 前 30 字里不出现任何抽象名词（「时代」「变革」「趋势」「范式」）。
- 开头不解释背景。背景放在第二个小标题之后，读者已经愿意读了再给。

### 钩子不是只在开头

体检脚本量的是**最长无钩区间 ≤500 字**。也就是说，每两三段就要有一次转向：

- 转折：`但问题是` `然而` `麻烦在于` `更要命的是`
- 悬念：`这里有个反直觉的地方` `我一开始也这么以为`
- 提问：`如果这事落到你头上呢？`
- 反证：给一个和上文相反的事实

**每个小节的最后一句，最好是一个把人推向下一节的句子。**
