# 利他性：读者带走了什么

体检脚本里最重的一条阻塞项叫 **`reader_benefit = 0`**，意思是：
全文没有任何读者可以带走的东西。

这条在本仓库里有个更狠的名字：**白看一场**。

## 为什么利他性直接决定涨粉

读者关注一个号，本质上是在做一个预测：**「以后这个号还会给我有用的东西」**。

单篇写得漂亮不构成这个预测。**「我从这篇里拿到了具体的东西」**才构成。

同理，转发的本质是社交货币——一个人转发你的文章，是因为这篇文章让他在朋友圈里
显得懂行、显得有判断力，而不是因为你写得漂亮。**他转发不了一种情绪，他转发的是
那句可以被复述的话。**

所以「可转述的结论」不是修辞要求，是分发要求。

## 四种利他物

**必须至少有两种**（体检脚本只有一种时扣 5 分）。

### 1. 判断标准

> 什么情况选 A，什么情况选 B。

这是最高价值的一种，因为它把「知识」变成了「决策能力」。

```
✅ 输出长的场景用 A，输入长输出短的场景两者差不多，别为这点差价换模型。
❌ 两个模型各有优劣，要根据实际情况选择。
```

第二句是万金油，等于没说。**判断标准必须能让读者当场做出一个不同的决定。**

### 2. 适用边界

> 什么时候这套办法失效，别硬套。

给边界的作者显得可信，因为他没有在推销。**主动说出自己方案的失效条件，
是建立信任最快的方式。**

```
✅ 团队少于 5 个人的时候，这套流程的维护成本高于收益，别抄。
```

### 3. 可执行步骤

> 今晚就能做的第一件事是什么。

要点是**颗粒度**。「加强监控」不是步骤，「打开那个配置页看第三项是不是默认值」才是。

### 4. 一句可转述的结论

> 短到能被复述，狠到值得被复述。

```
✅ 贵一倍不等于更强。
✅ 能被量出来的问题，就能被修好。
✅ 演示不等于部署。
```

判断法则：**这句话能不能被读者原样讲给同事听？** 需要读者自己再加工的，就不算。

## 按题材选形态，禁止模板强塞

这是本仓库反复踩过的坑：不管什么题材都硬塞一段「普通人该怎么办」。

| 题材 | 合格的利他物 | ❌ 硬塞会出事的 |
|------|------------|---------------|
| 工具/选型 | 判断标准 + 适用边界 + 清单 | —— |
| 行业机制拆解 | 因果链讲透 + 一句可转述结论 | 「三步教你应对」 |
| 历史/事件复盘 | **事实线清晰 + 影响与结局说明白** | 「普通人今晚怎么防」 |
| 人物 | 关键选择点 + 结局 + 一句判断 | 行动清单 |
| 政策/民生 | 谁受影响、影响多大、可检查的办事步骤 | 空泛口号、站队 |
| 财经（非投资） | 钱从哪来到哪去 + 代价落在谁头上 | 任何投资建议（**红线**） |

**事实线本身就是给读者的东西。**一篇把复杂事件讲清楚、让读者从此能跟人复述来龙去脉
的复盘，利他性是满的，不需要再挂一个行动清单。

## 结尾必须有落点

体检脚本单独检查**最后四分之一**：这一段里没有任何利他物就扣分。

理由很实际：读到最后四分之一的人是最有可能转发和关注的人。**在最愿意行动的地方
给他一个空转的结尾，是最贵的浪费。**

### 结尾禁区

```
❌ 让我们拭目以待。
❌ 未来会怎样，时间会给出答案。
❌ 你怎么看？欢迎留言讨论。      ← 把判断推给读者＝作者没有判断
❌ 总之，这是一个值得持续关注的话题。
```

这四句的共同点：**作者退场了。**读者跟着你走了 3000 字，结果你在终点说「我也不知道」。

### 好结尾的形状

- **回扣开头 + 给判断**：把开头那个场景再提一次，然后落一句结论。
- **对号入座**：「如果你是 X，就 Y；如果你是 Z，这事跟你没关系。」
- **不和解**：有些题材本来就没有解法，那就明确说「这事目前无解，但至少你现在知道
  卡在哪」——**说清楚问题在哪，本身也是利他。**

## 一个自查问题

写完之后，只问一句：

> **读完这篇，读者能带走什么？**

答不上来，就重写。答案是「一些思考」「一点启发」，也算答不上来。
