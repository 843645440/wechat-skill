# 读者带走什么（反「白看一场」）

强情感和观点不等于有用，但「有用」**不等于**每篇都塞防骗清单或行动 CTA。

合格标准：**读完能说清用户要讲的主线，并多带走一点认知或判断**——形态随题材变。

## 按题材选择增量（必读）

| 题材 | 合格的「带走」 | 不要硬塞 |
|------|----------------|----------|
| 职场/工具/选型/部署 | 可执行动作、判断标准、误读对照 | 纯情绪发泄 |
| 产业机制评论 | 机制一层 + 常见误读 | 假装读者能改国策 |
| **历史事件/案件复盘** | 时间线清楚、责任与处理、**遗留影响或当事人结局** | 「普通人怎么防」、假站队 |
| 人物叙事 | 行为—后果链条、结局与空白 | 鸡汤升华、强行清单 |
| 民生服务 | 可检查标准或下一步去哪办 | 空口号 |

用户 brief 写了「不要防」「不要我站哪边」→ **整类禁止**，即使用户没写，历史复盘默认也不开「防手册」「站队节」。

## 信息增量类型（按需选，不强制凑满 3 类清单）

| 类型 | 要求 | 适用 |
|------|------|------|
| **可核验事实锚** | 时间/主体/动作/来源性质 | 几乎都需要 |
| **机制一层** | 为什么会这样 | 评论、复盘 |
| **错误对照** | 通稿误读 vs 更准读法 | 有通稿话术时 |
| **可执行动作** | 读者真能做的具体事 | 仅当读者角色做得到 |
| **判断标准** | 怎样算过/还早 | 选型、验收类 |
| **影响与结局** | 行业/制度/当事人后来怎样 | **复盘与人物首选收束** |
| **边界** | 本文不谈什么、证据停在哪 | 敏感与未决案件 |

**历史复盘默认组合：** 事实锚 + 时间线 + 影响与结局。  
**不要**为了「利他模板」把「可执行动作」硬加给无权执行的普通读者。

## 禁止的伪利他

- 「五条防法」但读者既不是评审也不是公安  
- 「我站哪边」而法律/调查结论已清楚（废话站队）  
- 「你今晚可以做的」与文章主线无关  
- 遮住情绪后只剩正确的废话

## 与声口的关系

- 清单可以锋利，但必须**角色匹配**（读者真是那类人）。  
- 禁止为了有用而编造数据、内部案例。  
- 禁止写成无态度的纯手册——仍要有「我」和判断（若账号要求）。  
- 有用部分服务于文章，不是附录考核表。

## 自检（交付前）

- [ ] 用户 must_include 是否都在？must_avoid 是否都避开？  
- [ ] 遮住形容词后，主线（时间线/机制/结论）是否还在？  
- [ ] 若是复盘：影响或当事人结局是否写清？是否误塞了防骗 CTA？  
- [ ] 若是工具/职场：是否有动作或标准，而不是只剩情绪？  

任一项失败 → 同轮改，再交付。
