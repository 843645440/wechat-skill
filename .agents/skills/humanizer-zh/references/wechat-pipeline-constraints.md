# 公众号流水线约束

当输入来自 `wechat-content-pipeline`：

1. 只就地覆盖 `article.md` 一轮；文件内只留终稿。
2. 保留唯一一级标题、必要二级标题、链接、引用、表格和 1500—4000 字范围。
3. 不新增数据、引语、人物、案例、来源、亲历、采访、动机或结论；保留不确定性和生效状态。
4. 声口服从 `user-brief.md`：普通观点稿可用懂行者第一人称和强情感；公共事件档案或正式报道使用克制事实声口，不注入第一人称愤怒。
5. 情绪只能来自已有事实造成的机制、成本、责任和后果，不能靠夸张形容词制造。
6. 标题保持信息锚点，≤32 字；不要改成通稿，也不要改成猎奇悬念。
7. 空洞排比与海报口号应删；有事实或机制支撑的判断句、必要留人勾子可以保留。
8. 不把改写说明写进 `article.md`。

更细的执行尺度见流水线 `references/humanize-pass.md`；公共事件还须服从其 dossier、隐私标记和官方来源边界。
