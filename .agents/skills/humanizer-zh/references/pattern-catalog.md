# AI 写作模式目录

本表用于专项审阅。普通改写先执行 `SKILL.md` 的一轮流程，不必逐条扫描所有模式。

## 内容与归因

| 模式 | 常见信号 | 最短修法 |
|---|---|---|
| 1. 夸大意义 | 标志着、见证了、关键转折、深远影响 | 写实际发生了什么；无新增信息就删除 |
| 2. 强调知名度 | 被多家媒体报道、广受关注 | 只保留与正文有关的一条具体报道或事实 |
| 3. 句尾伪分析 | 从而彰显、进一步体现、确保了 | 拆成可验证事实；没有事实就删掉尾巴 |
| 4. 宣传腔 | 开创性、充满活力、令人惊叹、卓越 | 换成可观察的功能、规模、时间或结果 |
| 5. 模糊归因 | 专家认为、业内指出、多方消息 | 写明来源和时间；无法确认就删除或标不确定 |
| 6. 挑战与展望模板 | 尽管面临挑战，未来仍然可期 | 写已经发生的限制、应对和仍未解决的问题 |

## 语言与结构

| 模式 | 常见信号 | 最短修法 |
|---|---|---|
| 7. AI 高频词 | 此外、至关重要、赋能、格局、深入探讨 | 删连接词，换成普通动词和具体对象 |
| 8. 回避“是/有” | 作为、充当、拥有着、提供了一个 | 直接写“是、 有、 可以” |
| 9. 否定式排比 | 不仅……而且……；不是……而是…… | 直接陈述真正结论 |
| 10. 强凑三项 | 三个并列形容词、每处都分三点 | 使用事实需要的数量，不追求三段式 |
| 11. 同义词循环 | 主人公/核心人物/中心角色交替 | 用同一个准确称谓，合并重复句 |
| 12. 虚假范围 | 从 X 到 Y，但两者不是同一尺度 | 列出实际覆盖的项目或删除“从……到……” |

## 展示与排版

| 模式 | 常见信号 | 最短修法 |
|---|---|---|
| 13. 破折号过多 | 每段都用“——”制造转折 | 改句号、逗号或真正的因果关系 |
| 14. 粗体过多 | 每句都有加粗短语 | 只保留少量真正需要扫读的关键词 |
| 15. 内联标题列表 | “**性能：**…… **安全：**……” | 能成段就成段；确属步骤时保留列表 |
| 16. 英文标题式大写 | Every Major Word Capitalized | 按目标语言和专名规则正常书写 |
| 17. Emoji 装饰 | 🚀、💡、✅ 充当小标题 | 删除；用正文关系表达层级 |
| 18. 引号混乱 | 中文正文混用不合语境的英文引号 | 按文体统一中文引号，代码和原始引文除外 |

## 对话残留与回避

| 模式 | 常见信号 | 最短修法 |
|---|---|---|
| 19. 协作痕迹 | 当然、希望对你有帮助、请告诉我 | 删除，直接进入正文 |
| 20. 模型免责声明 | 截至训练时间、基于有限信息 | 换成真实来源边界；无来源则不要断言 |
| 21. 谄媚语气 | 好问题、你说得完全正确 | 删除评价，回应具体问题 |
| 22. 填充短语 | 值得注意的是、在这个时间点 | 直接写事实；“现在”通常已经足够 |
| 23. 过度限定 | 可能潜在地或许会产生一些影响 | 保留一个准确的不确定程度 |
| 24. 万能积极结尾 | 未来可期、迈出重要一步、令人期待 | 写下一项已确定行动、未决问题，或直接收束 |

## 判断优先级

先修事实风险和模糊归因，再修宣传腔与公式结构，最后才处理词频和标点。不要因为某个词出现在表里就机械删除：当它承载准确含义时可以保留，问题在于空泛、重复和无证据使用。
