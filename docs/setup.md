# 首次配置（给 Agent 读）

用户说「帮我配置公众号技能」或刚克隆完仓库时，读这一页，不要让用户去翻完整 README。

先跑：

```bash
python3 scripts/setup_status.py
```

按输出里的 `next_questions` 逐项问，只问缺失项。问完写入配置，回报已开/仍缺。凭证只进环境变量，不要写进 Git、文章或定时任务提示词。

## 必问

1. 要用哪个公众号账号？别名（如 `a` / `b`）、AppID、AppSecret。
2. 常用方式：已有成稿只要排版，还是给主题让 AI 写。
3. 若选成稿：去 AI 味默认关；用户要开再开。
4. 正文配图：开 / 关，默认关。
5. 要不要开科技/AI 系列选题 + 用哪个账号。

## 按需再问

- 打开正文配图，或明确要 AI 封面时：引导去 <https://platform.agnes-ai.cn> 领取免费 `AGNES_API_KEY`。
- 要进草稿箱：云端出口 IP 加入公众号后台 IP 白名单。
- 要科技/AI 系列日更：在用户自己的 Agent 定时任务里触发，本仓库不内置 cron。

## 写死的默认

- 输出到草稿箱，不公开发布，不等于群发给粉丝。
- AI 写作必须去 AI 味，不能关。
- 仓库默认系列是科技/AI。本机 `config/local/` 的配置不进 Git。
- 用户已给图优先，不覆盖。
